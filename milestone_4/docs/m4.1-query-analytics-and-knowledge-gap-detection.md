# Milestone 4.1: Query Analytics and Knowledge Gap Detection Module

## 📌 Executive Summary
The **Query Analytics and Knowledge Gap Detection Module (M4.1)** provides enterprise operational telemetry, continuous resolution monitoring, and automated detection of knowledge base deficiencies. By tracking every query resolution path, retrieval score, confidence value, and clarification interaction, the module transforms passive RAG logging into an active diagnostic radar that pinpoints missing organizational documentation.

## 🗄️ Telemetry Schema & Storage Architecture

Analytics data is persisted separately from the vector database in an indexed SQLite database (`data/analytics/analytics.db`) to ensure that high-frequency query auditing does not degrade vector index traversal.

### 1. `query_logs` Schema
| Field | Type | Description |
|---|---|---|
| `query_id` | `TEXT PRIMARY KEY` | Unique 16-character alphanumeric query identifier |
| `timestamp` | `TEXT` | UTC ISO-8601 timestamp with sub-second precision |
| `query_text` | `TEXT` | Raw user input query (text or speech transcript) |
| `effective_query` | `TEXT` | Standalone query after anaphora resolution or clarification |
| `domain` | `TEXT` | Detected domain (`machine_learning`, `computer_networks`, `cybersecurity`) |
| `query_type` | `TEXT` | Intent classification (`factual`, `procedural`, `comparative`, `ambiguous`, `multi_part`) |
| `route_target` | `TEXT` | Agent routing destination (`retrieval`, `clarification`) |
| `top_score` | `REAL` | Highest chunk similarity score ($s_{\text{top}}$) |
| `avg_score` | `REAL` | Mean similarity score across Top-$K$ retrieved chunks ($\bar{s}_{\text{top-}k}$) |
| `confidence_score` | `REAL` | Empirical confidence value: $C = 0.70 \times s_{\text{top}} + 0.30 \times \bar{s}_{\text{top-}k}$ |
| `confidence_level` | `TEXT` | Confidence bracket (`HIGH`, `MEDIUM`, `LOW`, `NONE`) |
| `has_sufficient_evidence` | `INTEGER` | Boolean flag (1 if evidence met threshold; 0 otherwise) |
| `status` | `TEXT` | `RESOLVED`, `LOW_CONFIDENCE`, `UNANSWERED`, `CLARIFICATION_REQUESTED`, `CLARIFICATION_RESOLVED`, `ERROR` |
| `retrieved_chunk_ids` | `TEXT` | JSON list of chunk identifiers |
| `sources` | `TEXT` | JSON list of cited document titles |
| `latency_ms` | `REAL` | End-to-end execution time in milliseconds |
| `input_modality` | `TEXT` | Input origin (`text` or `voice`) |

## 🔍 Knowledge Gap Detection Algorithm

The `KnowledgeGapDetector` automatically aggregates and clusters unfulfilled queries using the following methodology:

1. **Candidate Filtering**:
   Queries matching any of the following conditions are flagged as gap candidates:
   $$\text{Status} \in \{\text{UNANSWERED}, \text{LOW\_CONFIDENCE}\} \quad \lor \quad \text{has\_sufficient\_evidence} = \text{False}$$

2. **Semantic Keyword Clustering**:
   Stopwords are stripped, and token sets are clustered based on Jaccard overlap:
   $$J(Q_1, Q_2) = \frac{|T(Q_1) \cap T(Q_2)|}{|T(Q_1) \cup T(Q_2)|}$$
   Queries with $J(Q_1, Q_2) \ge 0.25$ within the same domain are fused into a thematic gap cluster.

3. **Severity Scoring Formula**:
   Each cluster receives an empirical severity score $S$:
   $$S = \text{frequency} \times (1.0 - \bar{C}) + 1.5 \times N_{\text{unanswered}}$$
   - **CRITICAL**: $S \ge 3.5 \lor N_{\text{unanswered}} \ge 2$
   - **HIGH**: $S \ge 2.0 \lor \text{frequency} \ge 2$
   - **MEDIUM**: $S \ge 1.0$
   - **LOW**: $S < 1.0$

4. **Actionable Remediation**:
   For each detected gap, the engine recommends specific documentation titles, technical concepts, and knowledge domain updates to guide organizational content authors.

## 📊 Analytics Dashboard Capabilities
- **Operational Metrics**: Total query volume, resolution rate (%), unanswered count, low-confidence count, clarification frequency, and average latency.
- **Knowledge Gap Radar**: Expandable cards displaying gap topic, severity badge, query volume, average confidence, sample prompts, and suggested document ingestion.
- **Multi-Dimensional Filters**: Slicing and grouping by domain, query type, confidence bracket, date range, and resolution status.
- **Query Audit Trail**: Searchable, paginated data table with JSON payload inspector for individual query debugging.
- **Data Export**: One-click download of operational telemetry in CSV and complete report in JSON.

# Milestone 4.4: Technical Architecture and System Data Models

## 🧩 Agent Responsibilities & Interaction Protocols

| Agent Name | Core Module | Primary Responsibility | Input Artifact | Output Artifact |
|---|---|---|---|---|
| **Conversation Memory Agent** | `memory.py` | Maintains multi-turn context; resolves pronouns (`it`, `its`, `they`); isolates domain switches. | Raw Query, `ConversationSession` | `effective_query` (str) |
| **Query Understanding Agent** | `query_understanding.py` | Detects knowledge domain, classifies intent, extracts key entities, evaluates ambiguity. | `effective_query` | `QueryAnalysisResult` |
| **Clarification Agent** | `clarification.py` | Identifies polysemy; proposes targeted options; fuses user clarification into refined query. | `QueryAnalysisResult` | `ClarificationRequest` / Refined Query |
| **Retrieval Agent** | `retrieval.py` | Performs hybrid vector-lexical search; applies domain affinity boost; ranks top-$K$ chunks. | `QueryAnalysisResult`, Top-$K$, Threshold | `RetrievalResult` |
| **Response Generation Agent** | `response_generation.py` | Synthesizes grounded answer; builds Transparency Panel payload; cleans speech text. | `QueryAnalysisResult`, `RetrievalResult` | `AgentResponse` |
| **Voice Module** | `voice.py` | Cleans markdown/code/citations for TTS audio; builds Web Speech configuration. | Raw grounded answer text | `VoicePayload`, `SpeechConfig` |
| **Analytics Tracker** | `tracker.py` | Captures telemetry; classifies resolution status (`RESOLVED`, `LOW_CONFIDENCE`, `UNANSWERED`). | `OrchestrationResult` | `QueryLogEntry` (SQLite) |
| **Knowledge Gap Detector** | `gap_detector.py` | Clusters unanswered and low-confidence queries; calculates severity; recommends ingestions. | `query_logs` | `KnowledgeGapReport` |

## 🗄️ Ingestion & Vector Indexing Pipeline

1. **Document Loading (`loaders.py`)**: Multi-format parsers supporting `.pdf` (PyMuPDF), `.docx` (python-docx), `.txt` (UTF-8), and `.csv` (Pandas/CSV). Automatically injects domain hints based on content signatures.
2. **Cleaning & Normalization (`cleaner.py`)**: Strips null bytes, normalizes line breaks, and condenses excessive whitespace.
3. **Chunking (`chunker.py`)**: Dynamic semantic windowing ($800$ characters, $150$ character overlap) preserving natural sentence boundaries (`. `, `\n\n`, `! `, `? `).
4. **Embedding Generation (`embedder.py`)**: Generates normalized 384-dimensional vector representations using `all-MiniLM-L6-v2` with an in-memory n-gram fallback.
5. **ChromaDB Indexing (`chroma_store.py`)**: Persists chunks, vectors, and primitive metadata (`document_name`, `chunk_id`, `domain`, `page`, `section`).

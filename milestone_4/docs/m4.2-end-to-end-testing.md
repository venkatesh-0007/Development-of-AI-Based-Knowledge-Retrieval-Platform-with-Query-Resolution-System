## 3. Canonical Query Archetypes Validated

1. **Factual**: `What is TCP?` -> Retrieved from `computer_networks.txt` with HIGH confidence.
2. **Procedural**: `How does DNS resolution work?` -> Step-by-step resolution retrieved.
3. **Comparative**: `Compare TCP and UDP.` -> Multi-document synthesis comparing connection-oriented vs connectionless.
4. **Ambiguous**: `Explain tree.` -> Detected polysemous term, requests clarification between Decision Tree, Spanning Tree, or Binary Tree.
5. **Multi-Part**: `What is TCP and how is it different from UDP?` -> Decomposed into sub-inquiries and synthesized.
6. **Multi-Turn**: Follow-up `What are its advantages?` -> Resolves "its" to "TCP" via Conversation Memory.
7. **Context Switching**: ML -> Networks -> Cybersecurity -> Memory correctly updates active domain without crosstalk.
8. **Unknown Query**: `What is quantum annealing?` -> Correctly classified as UNANSWERED / insufficient evidence, logged to knowledge gaps.
9. **Transparency**: Retrieved chunk snippets, confidence scores, and source documents match generated answer.
10. **Telemetry**: Analytics record created with latency, score, and resolution path.

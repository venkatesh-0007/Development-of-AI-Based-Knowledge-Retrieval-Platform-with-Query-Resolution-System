# M4.3 — System Optimization Methodology

## 1. Retrieval Optimization Strategy

The Milestone 4 retrieval architecture replaces pure vector similarity with a calibrated **Hybrid Retrieval & Dynamic Scoring Engine**:
1. **Dense Vector Search**: Computes normalized cosine similarity via sentence-transformer embeddings (55% weighting).
2. **Lexical Keyword Overlap**: Measures exact keyword and acronym co-occurrence across candidate chunks (45% weighting).
3. **Domain Affinity Bonus**: Applies a calibrated `+0.05` relevance bonus when document metadata matches the identified query domain.
4. **Calibrated Thresholding**: Configures an optimal similarity cutoff of `0.35` (calibrated down from rigid 0.45/0.55).
5. **Multi-Part Decomposition**: Splits compound interrogatives into independent sub-queries and aggregates candidate chunks across inquiries.

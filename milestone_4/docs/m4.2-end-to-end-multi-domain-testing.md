## 🛡️ Cross-Domain Context Switching Validation
A major challenge in multi-turn conversational RAG is **context bleeding**: when a user discussing Computer Networks suddenly asks about Cybersecurity, stale pronouns or entities (e.g., "TCP") must not contaminate the new domain.

The `ConversationMemoryAgent` employs explicit **context-switching detection**:
- When the incoming query contains explicit technical keywords from a different domain, the active domain binding shifts cleanly.
- Anaphoric pronoun resolution is bypassed, preventing erroneous cross-pollination.
- Document chunks from the prior domain are suppressed during retrieval.

# Milestone 2.1: Query Understanding Agent Specification & Evaluation

## 1. Overview

The **Query Understanding Agent** acts as the front-door intelligence in the multi-agent RAG architecture. It parses incoming user queries, classifies their semantic intent into four distinct categories (`factual`, `procedural`, `comparative`, or `ambiguous`), extracts target keywords/entities, generates confidence scores, and produces routing directives for downstream agents.

---

## 2. Classification Taxonomy & Decision Rules

| Query Type | Definition | Core Linguistic Indicators | Target Routing |
|---|---|---|:---:|
| **`factual`** | Queries asking for direct facts, definitions, properties, parameters, or specifications. | *"what is"*, *"define"*, *"which port"*, *"who is"*, *"meaning of"*, *"which layer"* | `retrieval` |
| **`procedural`** | Queries asking for step-by-step instructions, workflows, setup guides, or algorithms. | *"how to"*, *"steps for"*, *"process of"*, *"procedure to"*, *"algorithm for"*, *"how does ... work"* | `retrieval` |
| **`comparative`** | Queries analyzing similarities, differences, trade-offs, or comparisons between entities. | *"vs"*, *"versus"*, *"compare"*, *"difference between"*, *"pros and cons"*, *"better than"* | `retrieval` |
| **`ambiguous`** | Underspecified, vague, single-word (non-concept), or pronoun-only queries lacking subject context. | *"how to do it"*, *"tell me about that thing"*, *"which is better"*, isolated punctuation, empty strings | `clarification` |

---

## 3. Structured Output Schema

The agent emits a deterministic `QueryAnalysisResult` object:

```json
{
  "query": "Compare TCP vs UDP protocols in transport layer",
  "cleaned_query": "Compare TCP vs UDP protocols in transport layer",
  "query_type": "comparative",
  "confidence": 0.95,
  "route_to": "retrieval",
  "reasoning": "Contains explicit comparative terminology or multi-entity comparison.",
  "entities": [
    "TCP",
    "UDP",
    "protocols",
    "transport",
    "layer"
  ],
  "requires_clarification": false,
  "reformulated_query": "Compare TCP vs UDP protocols in transport layer"
}
```

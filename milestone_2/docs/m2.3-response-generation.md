# M2.3: Response Generation Agent Specification & Grounding Guidelines

## 1. Overview

The **Response Generation Agent (M2.3)** synthesizes accurate, user-friendly, and strictly grounded answers using context retrieved by the Retrieval Agent (M2.2). It prevents hallucinations, formats output based on query intent (Factual, Procedural, Comparative), attaches source citations, and computes application-level confidence indicators.

---

## 2. Query-Type Tailored Response Formatting

| Query Type | Formatting Strategy | Output Structure |
|---|---|---|
| **`factual`** | Concise, direct definitions and factual explanations. | Direct definition paragraph followed by structured bullet points of key properties. |
| **`procedural`** | Step-by-step sequential breakdown. | Numbered sequential instructions (`1.`, `2.`, `3.`) highlighting preconditions and steps. |
| **`comparative`** | Multi-entity side-by-side comparative analysis. | Structured section contrasting properties, advantages, and trade-offs. |
| **`ambiguous` / Unavailable** | Graceful fallback without hallucinated facts. | Clear notification stating that the knowledge base lacks sufficient evidence. |

---

## 3. Application-Level Confidence Scoring

The confidence indicator is computed dynamically using a weighted formula:

$$\text{Confidence Score} = 0.70 \times \text{Top Score} + 0.30 \times \text{Avg Top-K Score}$$

### Confidence Levels

| Level | Score Range | Color Indicator | Operational Meaning |
|---|:---:|:---:|---|
| **`HIGH`** | $\ge 0.75$ | 🟢 Green | High semantic alignment; strong factual grounding. |
| **`MEDIUM`** | $0.60 - 0.74$ | 🟡 Yellow | Moderate alignment; context provides partial evidence. |
| **`LOW`** | $0.45 - 0.59$ | 🟠 Orange | Weak alignment; answer should be verified. |
| **`NONE`** | $< 0.45$ | 🔴 Red | Below threshold or no relevant chunks found. |

---

## 4. Source Attribution & Citation Model

Every grounded response is accompanied by a structured `SourceAttribution` list:

```json
{
  "document_name": "computer_networks.txt",
  "chunk_id": "8f3b4c12-0",
  "relevance_score": 0.915,
  "snippet": "Transmission Control Protocol (TCP) is a connection-oriented, reliable protocol that uses a 3-way handshake..."
}
```

---

## 5. Strict Grounding Prompt Template

When an external LLM client is configured, the agent injects the following grounding prompt:

```text
You are a grounded knowledge base AI assistant.
Answer the user's query strictly using ONLY the factual information provided in the context below.
If the context does not contain enough information to answer the question with certainty, clearly state that the knowledge base does not contain sufficient details.

Rules:
1. Do not assume or extrapolate beyond the provided text.
2. Maintain factual accuracy and cite source references.
3. Structure your response appropriately (factual, procedural, comparative).

Context:
{context}

User Question: {query}
Query Type: {query_type}

Grounded Answer:
```

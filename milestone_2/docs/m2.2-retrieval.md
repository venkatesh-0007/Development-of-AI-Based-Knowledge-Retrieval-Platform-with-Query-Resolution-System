# M2.2: Retrieval Agent Specification & Validation

## 1. Overview

The **Retrieval Agent (M2.2)** performs semantic vector search against the indexed ChromaDB knowledge base using Sentence Transformers (`all-MiniLM-L6-v2`) embeddings. It consumes structured query representations from the Query Understanding Agent (M2.1), dynamically selects Top-K, filters low-confidence noise, and returns ranked, metadata-rich context chunks.

---

## 2. Core Capabilities

### 1. Dynamic Top-K Selection
Depending on the classified query intent:
- **Factual**: Retrieves focused Top-3 chunks to prioritize precision.
- **Procedural**: Retrieves Top-5 chunks to assemble full multi-step procedures.
- **Comparative**: Retrieves Top-5 chunks to ensure coverage across all compared entities.

### 2. Relevance Score & Confidence Threshold Filtering
- Uses cosine similarity scores: `similarity_score = 1 - cosine_distance` (range 0.0 to 1.0).
- Configurable `confidence_threshold` (default: **0.45**).
- Chunks scoring below the threshold are filtered out to prevent hallucinations in downstream generation.

### 3. Metadata Preservation
Each retrieved chunk retains:
- `document_name` / `source` (e.g. `ml_overview.txt`, `computer_networks.txt`)
- `chunk_id` (deterministic SHA256 document hash + index)
- `rank` (1-indexed order of relevance)
- `similarity_score` (cosine similarity metric)

### 4. Evidence Sufficiency Flag
- `has_sufficient_evidence = True` if at least 1 chunk passes the threshold.
- `has_sufficient_evidence = False` if no chunks meet the confidence requirement, signaling the downstream agent to issue a graceful no-result response.

## 3. Data Schema: `RetrievalResult`

```json
{
  "query": "What are the techniques to prevent overfitting?",
  "query_type": "factual",
  "top_score": 0.884,
  "total_retrieved": 3,
  "filtered_count": 0,
  "has_sufficient_evidence": true,
  "confidence_threshold": 0.45,
  "chunks": [
    {
      "chunk_id": "a1b2c3d4-0",
      "rank": 1,
      "similarity_score": 0.884,
      "content": "Techniques to prevent overfitting include: Regularization, Cross-validation, Early stopping...",
      "metadata": {
        "source": "ml_overview.txt",
        "chunk_index": 0
      }
    }
  ]
}
```

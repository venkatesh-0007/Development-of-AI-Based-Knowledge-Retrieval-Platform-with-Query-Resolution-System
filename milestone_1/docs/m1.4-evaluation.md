# M1.4 — Retrieval Validation

## Evaluation protocol

Use two knowledge domains, for example:

1. Machine Learning
2. Computer Networks

Prepare questions of four types:
- Factual
- Procedural
- Comparative
- Unavailable-information

For every question, record the expected source/chunk and compare it with the retrieved Top-1, Top-3 and Top-5 results.

### Metrics

For N test questions:

`Top-K Accuracy = questions where the expected source appears in the first K results / N`

Report the result as a percentage.

## Limitations
- Fixed chunking can divide closely coupled contextual sentences.
- Pure vector similarity without query classification treats all intents identically.
- No confidence thresholding in M1 basic retrieval (addressed in M2).
- Scanned/image-only PDFs require OCR, which is outside the basic M1 implementation.

## Milestone 2 Enhancements
- Query Understanding Agent (M2.1) classifies queries into 4 explicit categories.
- Retrieval Agent (M2.2) applies dynamic Top-K and threshold filtering (score >= 0.45).
- Response Generation Agent (M2.3) provides grounded synthesis, confidence metrics, and citations.
- Multi-Agent Orchestrator (M2.4) coordinates pipeline execution.
